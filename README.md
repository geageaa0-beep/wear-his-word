# Wear His Word - Premium Christian Streetwear E-Commerce

A modern, premium e-commerce website for Christian streetwear brand "Wear His Word."

## Brand Vision

**"If you can't preach with your mouth, preach with your shirt."**

Wear His Word is a faith-based clothing brand that allows young Christians to express their faith through premium, stylish streetwear featuring Bible verses, Christian messages, and faith-inspired designs.

## Features

- **Premium Editorial Design** - Minimal, modern aesthetic inspired by high-end fashion brands
- **Full E-Commerce Functionality** - Product catalog, cart, checkout, wishlist
- **Responsive Design** - Mobile-first approach optimized for mobile discovery
- **High-Performance** - Optimized images, lazy-loading, fast transitions
- **Subtle Animations** - Premium motion design that feels sophisticated, not gimmicky
- **SEO-Friendly** - Optimized for Christian clothing, Bible verse searches

## Target Audience

Young Christians (Gen Z and young adults) in Lebanon and the Middle East who want modern, premium Christian clothing that feels fashionable and authentic.

## Brand Colors

- **Black** - Primary
- **Off-white/Cream** - Secondary
- **White** - Accent
- **Subtle Grays** - Supporting (when necessary)

## Typography

- **Headings**: Modern sans-serif (strong, contemporary)
- **Editorial/Verses**: Elegant serif (sophisticated, timeless)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
